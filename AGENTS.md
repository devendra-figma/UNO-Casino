# Client-approved layout constraint

The existing design and layout are finalized and client-approved. Preserve them exactly unless the user explicitly requests a specific layout change. Do not independently redesign, restructure, resize, reposition, or improve components. Preserve spacing, dimensions, typography hierarchy, card structure, assets, and section composition. Implement only the requested changes, and keep unrelated functionality and product logic unchanged. Theme changes may change colors and visual surfaces only; geometry must remain identical between themes.
